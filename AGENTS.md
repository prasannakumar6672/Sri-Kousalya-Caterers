# Sri Kousalya Catering & Cooking Services

This repository contains the standalone web application for Sri Kousalya Catering & Cooking Services in Visakhapatnam.

## Architecture

- **Framework**: React 19 + Vite (SPA)
- **Routing**: React Router (react-router-dom)
- **Styling**: Tailwind CSS v4 (@tailwindcss/vite)
- **Icons**: Lucide React
- **Language**: TypeScript
